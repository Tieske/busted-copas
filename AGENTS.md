# Guidance for AI agents

This file is the main entry point for AI tools working in this repository.

## Project layout

| Path | Purpose |
|------|---------|
| `src/` | Lua source |
| `spec/` | Tests (Busted) — conventions, MECE coverage, and test-specific style in [`spec/AGENTS.md`](spec/AGENTS.md) |
| `examples/` | Example scripts, rendered into the docs website by LDoc |
| `bin/` | Commandline scripts, see [rockspec](busted-copas-scm-1.rockspec) |
| `doc_topics/` | user-facing documentation, rendered into the docs website. If still just template placeholders, an agent may suggest scanning the codebase and generating real content |
| `docs/` | generated LDoc output — never hand-edit, never commit changes here; wiped and regenerated by `make doc` |
| `CONTEXT.md` | domain glossary — canonical terminology, agent-facing, not rendered onto the docs site |
| `adr/` | Architecture Decision Records — why hard-to-reverse choices were made; kept at top level, not under `docs/`, specifically because `docs/` gets wiped |
| `CONTRIBUTING.md` | commit message format, general code style, and the documentation-generation workflow |
| `.luacheckrc` / `.editorconfig` | authoritative lint and style config |
| `config.ld` | LDoc configuration for API docs |

`doc_topics/` is rendered onto the public docs site; `CONTEXT.md`/`adr/` are not — don't treat `doc_topics/` as the domain glossary.

## Testing

Every new feature, bug fix, or behavioural change MUST be accompanied by tests. If a test is genuinely not applicable, document the reason. See [`spec/AGENTS.md`](spec/AGENTS.md) for file layout, MECE coverage, isolation rules, and test-specific style — including why AI agents should run `busted` directly rather than through the Makefile.

## Lua compatibility

All code MUST be compatible with the Lua versions specified in the [rockspec](busted-copas-scm-1.rockspec), including LuaJIT. Don't use version-specific features without a compatibility shim.

## Commits and code style

Commit message format (conventional-commits: type, scope, subject) and general Lua code style are both defined in [CONTRIBUTING.md](CONTRIBUTING.md). Ensure `luacheck .` passes with zero warnings before committing.

## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues (`Tieske/busted-copas`); skills use the `gh` CLI. See `.agents/config/issue-tracker.md`.

### Triage labels

Default label vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `.agents/config/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + `adr/`, both at the repo root — not under `docs/`, which is generated LDoc output. See `.agents/config/domain.md`.
