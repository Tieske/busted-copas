## What this project is

User-facing context can be acquired from `doc_topics/` (to prevent duplication here). If the contents are still just the template placeholders, then an AI Agent may suggest to scan the codebase and generate/update the contents.

For domain terminology and past architectural decisions, see `CONTEXT.md`
and `adr/` instead — those are agent-facing and distinct from `doc_topics/`:
`doc_topics/` is rendered onto the public docs website, `CONTEXT.md`/`adr/`
are not.

## Testing

**Every new feature, bug fix, or behavioural change MUST be accompanied by tests.** Do not submit code changes without corresponding test coverage. If a test is genuinely not applicable, document the reason.

For test file conventions, isolation rules, code style, and vertical whitespace rules, see **[spec/AGENTS.md](spec/AGENTS.md)**.

## Lua compatibility

All code MUST be compatible with the Lua versions specified in the [rockspec](busted-copas-scm-1.rockspec). This includes LuaJIT. Do not use features specific to a single Lua version without a compatibility shim.

## Code style

Code style is defined in [CONTRIBUTING.md](CONTRIBUTING.md). Ensure `luacheck .` passes with zero warnings before committing.

## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues (`Tieske/busted-copas`); skills use the `gh` CLI. See `.agents/config/issue-tracker.md`.

### Triage labels

Default label vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `.agents/config/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + `adr/`, both at the repo root — not under `docs/`, which is generated LDoc output. See `.agents/config/domain.md`.
